# Student Performance Analysis Dashboard

## Overview
Developed an interactive Power BI dashboard to analyze student academic performance using Power BI.

## Features
- KPI Cards
- Attendance Analysis
- Subject-wise Performance
- Interactive Filters (Slicers)
- Performance Trends

## Tools Used
- Power BI
- DAX
- Power Query
- Excel
